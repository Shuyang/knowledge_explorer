How to learn a relative ordering of items for a query, rather than an absolute score for each item.

Pairwise loss

Optimizes preferences between pairs: for a query, the more relevant item should score above the less relevant one by some margin.

InfoNCE

A contrastive objective that frames learning as picking out the one positive example from a set of candidates that are mostly negatives.

Formula Edited
ℒi = −log exp( sim(qi, ki+) / τ ) Σj exp( sim(qi, kj) / τ )

qi is the query embedding, ki+ its positive key; the sum runs over the positive plus all in-batch negatives.

Temperature τ
New

Rescales the similarity scores before the softmax. A smaller τ sharpens the distribution, so hard negatives dominate the gradient; a larger τ spreads attention across all negatives.
