One block at a time

Interaction spec. Every action targets exactly one block. The page only shows what the user has seen; prepared-but-unseen content has no visual presence.

01 · Lifecycle

Drafts are marked; the page is not

Temperature τ

Rescales similarity scores before the softmax…

Draft · temporary: tinted, with a ✓ to ink it

Formula

ℒ = −log( exp(s⁺/τ) / Σ exp(s/τ) )

Inked · the normal page: plain, no marker

Inked is the norm: most of a mature page is inked, so inked blocks carry no marker at all. Drafts are temporary and the only thing marked, by a faint blue tint and a ✓ at the right. Ticking ✓ lifts the block onto the plain page (~250 ms). Ink means “accepted into my page”, not “favorite”.

Generated content never appears: no placeholders, ghost rows, “ready” dots or counts. Suggestions are phrased as questions and don't reveal whether an answer is prepared.

⇔Sidebar: drag its right edge to resize (200–480 px, remembered; double-click resets). Each topic row has ··· on hover with Delete topic…, confirmed in a dialog.
✎Click a title or body to edit it in place. No Save/Cancel buttons: click outside to save, Esc cancels, ⌘↵ saves; paste or drop an image to insert it.
⋮⋮Grip: drag to move; click for the same menu as ···. Moving an inked block under a draft parent offers to ink the new parent chain (“Always ink the new parent chain” skips the question); declining cancels the move. There is no un-ink: edit or delete instead.
✓Ink: a faint ✓ at the right of every draft block, always visible since inking is the normal next step. Inks this block only, under an inked parent (the root is always inked). If parents aren’t inked yet it offers “Ink the chain” in one step; “Always ink the whole chain” skips the question. Side links need both ends inked.

06 · Safety & access

Calm by default

·Autosaves locally; reopening returns to the last block in view.
·Deleting a linked block lists the impact; relation notes are kept by default; 10 s undo.
·“Clean up” removes un-inked blocks after a preview. Inked blocks are never touched.
·Controls reachable by Tab on a focused block; ink state is announced as text, not colour alone.
